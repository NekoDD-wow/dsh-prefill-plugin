# 角色卡、世界书与故事记忆

角色卡在插件中是**预设体系的一部分**：卡片编译出系统提示、开场对话、每轮注入与工具权限（并附带世界书与故事记忆），预设可在卡片之上覆写部分格子，当前会话还可继续手改。

> **分层继承顺序**：默认 ← 角色卡 ← 预设覆盖 ← 本会话手改  
> 各分节标题旁都会标出当前来源：**来自角色卡 / 来自预设 / 本会话改过**。

---

## 导入、管理与套用

- **导入与导出**：在左栏「角色卡」导入 SillyTavern 角色卡（V2/V3，`.json` 或 `.png`），可查看详情、导出（PNG 卡会写回 `chara` / `ccv3` 块）或删除；重名卡自动显示副标区分。
- **我的名字（`{{user}}`）**：填写后会替换角色卡中的 `{{user}}` 占位符；已套用角色卡时修改名字并确认会触发重编，只更新仍保持角色卡原样的格子，不冲掉你手动改过的部分。
- **套用方式**：在头部「当前预设 ▾」的「角色卡」分组中直接点选（或在角色卡面板点直接套用按钮）。套用任何预设或角色卡均执行**整体替换**，不残留上一个预设的配置。

---

## 角色卡专属选项（就地调整）

角色卡的编译选项直接放在对应的功能节顶部：

- **系统提示 → 角色卡模式**：
  - **带工具（Agent）**：保留 DSH 官方系统提示、工具和审批，将角色设定追加在后面。
  - **纯角色扮演**：接管系统提示，只发送角色设定，不带工具与运行时上下文。
  - 切换模式会自动重新编译人设。
- **开场对话 → 开场白**：有多条备选开场白时可下拉切换，选中即替换第一条 AI 回答；若手动编辑过第一条，此处会标为「已改过」。
- **每轮注入 → 角色提醒 / 中文思考 / 第一人称思考**：按勾选项编译角色卡附带的每轮提醒（默认开启，可随时用左栏开关关闭）。
- **工具白名单**：在「会话沙盒 / 改写注入 → 工具放行」中调整（角色卡自带的白名单照常生效）。

---

## 基于角色卡的稀疏预设

套着角色卡点击「另存为…」时，默认勾选 **「基于角色卡」**：
- 只保存你相对角色卡改动过的格子，其余格子在下次套用时动态从角色卡读取（更新角色卡本体后，引用它的预设也会同步受益）。
- 读取旧版预设中存放的卡片选项（开场白、提醒、中文 / 第一人称、模式、白名单）时会自动迁移到对应分节。

---

## 世界书（Lorebook）与故事记忆

当套用的角色卡包含世界书或故事记忆时，这两项会挂载在左栏「角色卡」下方；两项均可由左栏开关单独停用，且保留内容。

### 世界书
- **常驻条目**：直接编入角色人设段。
- **关键词条目**：每轮扫描最近 4 条对话，命中关键词（支持全词匹配、正则与次级关键词）后将该条设定作为背景塞入本轮上下文。
- **就地编辑**：可在「世界书」分节搜索、展开全文、增删改条目；改动仅对本会话生效，保存为预设时会整份存进预设，**不会修改原角色卡文件**，并支持一键还原为角色卡原版。

### 故事记忆
- 长对话中每 8 轮在后台自动将前情提炼为摘要（人物关系、已发生事件、约定与伏笔、当前状态），后续作为背景发给模型，减少长程遗忘。
- 面板中可随时查阅、手动编辑或清空摘要（带二次确认与防丢草稿保护）。

---

## 清空 / 取消预设

点击卡片头部「保存」旁的 **「清空预设」**（或预设下拉底部的 **「取消预设」**），会将角色卡、系统提示、每轮注入、世界书、记忆与开场对话草稿全部归位（会话已开跑时只清草稿、不动历史），并在底部弹出**撤销条**，几秒内可一键放回清空前的全部配置与草稿。
