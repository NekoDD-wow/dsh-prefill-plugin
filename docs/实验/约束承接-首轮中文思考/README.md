# 接缝轮中文思考：对照实验（deepseek-flash）

日期：2026-10-27（Asia/Shanghai）。仓库（feat/constraint-carry，基线 c4142d4）。

## 设置
- 同一份从 `'*'`-only 会话存的预设：`preset.json` 的 everyTurn（内置「中文思考」积木，always，`seam: true`）。
- 同一组开场历史：4 轮英文问答（`items_base.json`；头部规则版 `items_head.json`；带中文思维链版 `items_head_r.json`）。
- 8 组英文提问（`questions.json`），第 i 次运行用第 i 组：首轮问题 + 第 2 轮问题。各变体共用同一组。
- 每次运行 = 新会话（`mksess.mjs` 预建）→ 物化开场 → 首轮 → 第 2 轮（同会话续跑），**串行**，经代理 8897 抓请求体。
- 指标：每轮思维链中文占比（`inject-auto.js` zhRatio，去代码后），≥0.8 算通过；模型这一轮没出思维链（n/a）按 0 / 不通过计。
- 中文系统提示：`zh_system.txt`（短版中文系统提示，含「【思考语言】思维链必须全程使用中文」），以 gate `replace` + overrides 写入（工具照旧）。
- 头部拼接：开场历史最前面一条 `【预填装 · 规则】以下要求对本会话全程有效：你的思维链（reasoning）请全程用中文……`。
- 加强尾部措辞（V3–V7）：`以上历史均遵守这些要求，继续保持。下面是一条新消息，本轮同样适用：思维链从第一句起就用中文，全程不切换成英文。`
- 实验开关（只在实验期间存在，已删除）：`PREFILL_EXP_SEAM`（off / line:<句>）、`PREFILL_EXP_SEAM_POS=end`、`PREFILL_EXP_SYSFIX`。

## 实验中发现的根因线索
基线请求体里，接缝轮在「接缝提醒 → 用户消息 → 运行时上下文」**之后**还有一条完整的英文 system 消息（4274 字，含 Agent Teams 段）。
原因：插件物化开场时写的 system/message 是 `agent/created` 时渲染的（2421 字，那时 Agent Teams 段还没挂），dsh-agent-loop
`SystemPromptProjection` 在第一条真实消息那一步发现不一致就追加一条 system/message。第 2 轮起不再追加，但历史里一直带着两份。
因此加了 V8（只修这个：把开场那条 system 在 `agent/request` 座位原地替换成本步渲染结果）、V9、V10 三个变体，VF 是最终提交的代码，VH 是插件版「开场里留一份规则」。

## 作废的运行（不在表里）
- V5 第一次冒烟：dsh 从继承的 stdin 读等到超时，首轮没跑；之后脚本加 `</dev/null` 重跑。
- V8 前两次：对齐写在 pre-step 里，替换事件落在 `step/start` 之前，会话日志重放校验失败（`system/message does not match an open turn and step`），第 2 轮起不来；改到 `agent/request` 座位并带当前轮 / 步后正常（之后 24/24 续跑成功）。
- VH 第一批：插件版头部规则只接了 `materializePrefill`，产品路径 `onInboxInserted` 没接，前 5 次没写进规则；修好后整批重跑。

## 结论
1. **中文系统提示是决定性的**：V1 15/16，V5 / V6 8/8；只要系统提示是中文且写了思考语言要求，首轮和第 2 轮几乎都过。头部 / 尾部 / 中文思维链在它之上看不出额外收益（已经到顶）。
   V1 用 replace 同时消掉了追加的英文 system；但 V8 / VF（只消掉追加的 system、系统提示仍英文）合计只有 6/24，所以起作用的是系统提示的语言，不只是去掉那条 system。
2. 不改系统提示时，所有插件侧手段都在 0%–60% 之间浮动：头部规则单独 0/8；尾部加强 3/8；头 + 尾 5/8；尾部挪到最末 3/8；对齐 6/24；对齐 + 头 9/16；对齐 + 头 + 通用加强 6/16；插件版头部规则 0/8。
   **同一配置两批能差 3–4 次（V9 6/8 → 3/8，V10 1/8 → 5/8，V8 5/8 → VF 1/8、0/8）**，每格 8 次只分得出「中文系统提示 vs 其他」这种大差别，头部 / 尾部 / 措辞之间分不出高下。
3. 第 2 轮基本跟着首轮走（首轮英文思考 → 第 2 轮常也英文），c4142d4 里「第 2 轮起 1.00」在这组数据里不成立（V0 合计 8/16）。对齐后第 2 轮 VF/VFb 14/16、V8 6/8（合计 20/24），可能与历史里不再有第二份英文系统提示有关，样本不大。

## 落地（提交到 feat/constraint-carry）
- **默认开**：开场系统提示对齐（`gate.alignOnRequest` / `alignSyntheticSystemPrompt`，`impl.js` 挂 `agent/request`）。理由：它修的是实打实的问题（接缝轮末尾多一整份系统提示、此后历史里两份），零 token 代价，失败回退原行为；对中文思考的帮助不显著，CHANGELOG 里如实写了。
- **不合入**：头部拼接 / 「开场里留一份规则」。插件版实现 + 单测都做了（补丁存 `with-headRule.patch`、`opening-seam.with-headRule.test.mjs`），但 VH 0/8、合计看不出收益，按「若有效才做成默认开」的要求没合。
- **不改**：接缝措辞（通用加强版 V10 不比默认句好）。
- **只写进文档**：中文系统提示（README + CHANGELOG 建议；插件不改用户系统提示）。
