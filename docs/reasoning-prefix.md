# 思考前缀（实验功能，默认关，已冻结）

> **已冻结（2026-11-21）**：该实验功能不再迭代 —— 代码、面板、结果行与日志功能保留供已启用用户继续使用，但不再新增功能或做新版本兼容性适配；外部仅针对该模块的 PR / Issue 默认不接收。

在左侧栏「预填装 → 实验 · 思考前缀」中启用。该功能基于官方 Chat Prefix Completion 能力，让模型每轮以固定文本开头；默认关闭，仅在官方 DeepSeek beta 上游验证过。

---

## 七件必须先知道的事

1. **只认官方 beta 上游**：前缀续写是官方 API 能力，插件仅做转发；切换第三方中转或本地模型时前缀可能被忽略。
2. **必须剥离 `tools`**：官方前缀续写不接受 `tools` 字段，代理会剥离本轮 `tools`，改为在提示词中注入**文本工具清单**，并将模型输出的 DSML 文本流改写为 `tool_calls`。清单是模型唯一的工具认知来源且永不为 0 字节；剥离 `tools` 后请求形态与普通轮不同，做对照实验时需将其视为变量。
3. **路由需手动切换并校验**：启用后插件会写入一条模型路由「DeepSeek Flash（思考前缀）」，但 DSH 会话模型归宿主管理，你需要在输入框下方的模型选择器里手动切换，并在发出一轮后回实验区核对「本会话路由」是否显示「已走前缀路由」。
4. **前缀本身不会回显**：官方接口仅返回续写部分，你写的前缀不会在回复中重复出现。
5. **清单注入模式会影响历史**：「清单注入」默认每轮注入（缓存友好）；切为「仅首次进历史」会把清单永久写入本次会话，切回也不会撤销。
6. **自动停用会移除 provider 路由**：连续失败达到阈值时自动停用并删除对应 `providers` 路由，仍指向该路由的会话会报 `NO_ADAPTER`。请先切回普通模型再决定是否重新启用。
7. **仅支持流式请求（缺省按流式处理）**：DSML 到 `tool_calls` 的改写仅能在流式响应上完成：
   - 显式携带 `stream: false` 的请求会直接返回 **HTTP 400**（不打上游）。
   - 不带 `stream` 字段的请求**按流式处理**（返回 SSE，与 OpenAI 缺省非流式相反；这是为兼容 DSH 自身请求而定）。第三方客户端请显式传 `stream: true`。
   - 关闭「流式改写（shim）」时为原样透传，不拦截非流式请求。

## 常见问题排查顺序

（核对完仍不生效请重启一次 DSH）

| 现象 | 排查位置 |
| :--- | :--- |
| 模型选择器里没有「思考前缀」 | 查看实验区「模型路由」胶囊，点击「修复路由」 |
| 面板提示「代理没在跑」 | 端口占用或代理未起，点击「修复路由」 |
| 已切模型但提示未走前缀路由 | 回模型选择器重新确认选中「思考前缀」条目 |
| 回复很长但看不到思考 | 前缀只规定开头，是否输出思考通道由模型决定 |

## 做实验：结果行、分臂、轮转与采样

### 结果行（默认开）
每发一次前缀请求，向 `<数据目录>/reasoning-result.jsonl` 追加一行 JSON（路径可在面板修改），方便脚本批量统计：

| 字段 | 含义 |
| :--- | :--- |
| `requestId` | 每请求唯一；**请按它去重，勿按行计数** |
| `variant` / `attempts[]` | 最终生效变体 / 实际尝试序列及上游状态码 |
| `sessionId` / `turn` / `step` | 归属会话与轮次（启发式匹配，无法唯一命中时为 `null`） |
| `routeConfidence` | `exact`（请求头直给）/ `content`（末条消息指纹唯一命中）/ `none` |
| `armId` / `runId` | 实验臂与轮次标识（发起时快照） |
| `catalogBytes` / `catalogMode` | 注入工具清单大小与模式 |
| `sampling` | 实际发给上游的采样参数（不保证上游完全遵守） |
| `prefix` / `usage` / `ms` / `firstDeltaMs` | 前缀长度 / token 用量 / 总耗时 / 首块延迟 |
| `verdict` | `reasoning-collected` / `no-reasoning` / `unknown` / `passthrough` / `skipped` / `ignored` / `error`（`≤ 0.21.8` 旧日志还可能出现已废弃的 `prefix-kept` / `prefix-absent`） |
| `autoDisabled` | 本请求是否触发了自动停用 |
| `clientAborted` | 客户端提前中止（如点击停止）；计 `ok: false` 但不计入连续失败自动停用 |

- **`verdict` 只记事实，不判「前缀是否被延续」**：因官方续写不回显前缀，`reasoning-collected` 仅代表采集到了思维链正文；判断前缀是否生效需通过 **`armId` 跨臂对比**（`prefix.reasoningLen > 0` 看 `reasoningHead`，`prefix.contentLen > 0` 看 `textHead`，两项分别受「收集思考」「正文片段」开关控制）。
- **隐私**：默认记录输出头 80 / 尾 40 字（`textHead` / `textTail`），不希望落盘可关闭「正文片段」。
- **关联置信度**：建议统计时按 `routeConfidence` 过滤或分组。

### 分臂（`armId` / `runId`）
代理为单进程单份全局前缀，**同一实验臂必须在独立会话中串行运行**，切勿多会话并发混跑不同臂（会导致静默串味）。

### 日志轮转与磁盘上限
结果行、代理日志、调试三件套与前缀轮日志共用大小轮转策略：单文件超限即顺延重命名为 `.1` / `.2` / `.3`，新数据继续写入原文件名。默认单文件 **8 MB × 保留 3 个历史**（每个日志族上限 32 MB，可在面板调整；设为 `0` 关闭轮转）。轮转严格发生在行边界（`proxy-raw.log` 为原始字节流，发生在数据块边界）。

### 采样参数与旋钮快照
- **采样覆盖（`temperature` / `top_p` / `seed`）**：留空即不干预；填写后会覆盖所有变体（含透传兜底臂，以防对照组引入额外混淆变量）。开启后透传臂不再原样转发字节。
- **预设旋钮快照**：保存前缀预设时会一并快照当前全量实验旋钮（端口与日志路径除外），套用时同步恢复。
- **清单重复提示**：若先用「仅首次进历史」再切回「每轮注入」，装配出口会自动去重只保留最新一份并提示审计警告（绝不删除唯一清单）；彻底清理请新开会话。
