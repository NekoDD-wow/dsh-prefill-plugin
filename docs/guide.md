# 功能详解与进阶用法

本文覆盖预填装卡片的日常操作、首轮锁定机制、把会话存成预设、手动/改写注入、全局设置页及插件文件结构。

---

## 弹出卡片布局与交互

- **左栏与右栏**：左栏依次为角色卡（套用带世界书 / 故事记忆的卡时挂在其下）、系统提示、工作区说明、每轮注入、开场对话、会话沙盒、用量与缓存；右栏只显示当前选中项。左栏支持键盘方向键漫游切换。
- **头部三区**：
  - **左区**：当前预设下拉（内置 / 我的预设 / 角色卡，带吸顶搜索与不裁切说明栏）+ **保存** + **清空预设**（一键清空当前预设与配置并弹出底部撤销条；预设下拉底部仍保留「取消预设」）。
  - **中区**：1 个状态胶囊（状态胶囊显示「首轮未发送 / 已锁定」· 拦截档位 · 缓存命中；点开查看首轮/每轮 token、工具数与当前模型名）。
  - **右区**：`⋯` 菜单（另存为、导出预设、引导、动效偏好）+ 钉住 + 收起 + 关闭。
- **收起 ≠ 关闭**：点 **收起（⌄）** 只是把卡片缩成输入框旁的标记（悬停 160ms 或点击即可展开）；点卡片外部或按 `Esc` 同样关闭（钉住后不自动关闭）。
- **自适应尺寸**：桌面与窄屏高度收敛为 `min(56vh, 540px)`，`< 820px` 窄屏左栏转为顶部标签，`≤ 480px` 手机端转为顶栏之下的全宽浮层。
- **单独停用并保留内容**：左栏每项（用量与缓存除外）右侧开关关闭后只停用该项，正文/配置原样保留，再次打开即恢复；开关状态随预设一并保存和套用。系统提示与开关改动从**下一轮**生效。

## 系统提示与工作区说明

### 系统提示三种模式
- **追加**：在 DSH 默认系统提示后追加自定义段落（工具、工作区与审批机制照旧）。
- **替换正文·保留工具**：用你的文本替换默认系统提示正文，工具和运行时上下文照旧（内置「🀄 中文版官方系统提示」即为此模式）。
- **接管**：系统提示只剩你写的这段，清空默认提示、运行时上下文与工具，效果等同直接调 API。

核心长文本框（系统提示、工作区说明、故事记忆、每轮注入）均采用一体式编辑器容器，底栏实时展示字数 / 估算 token、保存状态与清空 / 填入原文 / 一键展开高度操作。

### 工作区说明（`AGENTS.md` / `CLAUDE.md`）
DSH 会在首轮请求前把 `~/.dsh/AGENTS.md` 与工作区沿途的 `AGENTS.md` / `CLAUDE.md` 发送给模型，会话中途遇到子目录说明还会补发。本节控制其发送方式：
- **原样**（默认）：不做改动。
- **关闭**：首轮及中途补发均丢弃。
- **改写**：替换为你的正文（只进历史一次），下方只读区可对照原文并一键填入编辑框。

## 首轮锁定与手动注入

### 首轮锁定
会话第一次发送消息时，插件会记录写进历史的开场对话与当时的整套配置（持久化在 `state.json` 的 `locked` 字段，DSH 重启不丢失）。状态胶囊显示「首轮未发送 / 已锁定」：
- 锁定后，开场对话区顶部只读列出已写入历史的内容，下方列表仅作为「另存为预设」的工作区，改动不再影响当前会话。
- 每轮注入的「只在首轮」段仅在会话第一条真实消息那轮发送。

### 开跑后套用预设与恢复开局
- 会话开跑后再切换预设：系统提示、每轮注入、工具与世界书照常更换（下一轮生效）；预设中的开场对话不再写入（提示使用「手动注入」补充），「只在首轮」段默认跳过，可在每轮注入里勾选「下一轮发一次」。
- **恢复开局时的预设**：把配置换回开跑时快照（下一轮生效、不改历史；自动模式接着开局以来的判定继续，不从头预热）。旧版本开跑的会话也会显示已锁定，但无开局快照可恢复。

### 手动注入
位于开场对话下方，首轮前后均可使用：
- 选择「用户说 / AI 回答」填写内容并点击注入（支持 `Ctrl/Cmd+Enter` 发送、`Esc` 收起不误关大卡），**只发一次**：AI 运行中会在下一步插话，空闲时随下一轮发出；发出后进入真实历史，不再重复发送。
- 未发出前可随时编辑或撤回。「AI 回答」会以带标注（「剧情补充 · 由用户添加」）的 user 消息发出。存为预设时手动注入按角色取回。

## 把会话存成预设（从某一轮接着聊）

聊到一半想换走向、或想把优质开局反复复用：在头部点击「保存 / 另存为…」或开场对话里的「从当前会话取」。

- **开场对话截取**：抽取用户原话与 AI 回答转为开场对话；可选「带上思维链」与轮次范围 `第 N–M 轮`（用作分支点）。
- **整套配置同步保存**：系统提示、工具权限与开关一并写入预设。
- **每轮注入与约束承接**：
  - 可选「带上每轮注入设置」（保存的是规则/正文/检查项，新会话从头判定）。
  - 「从当前会话取」后会自动列出「会话里生效过的每轮约束」（从会话日志中实际发过的每轮注入识别），默认勾选编入预设并带「来自会话」标记；新会话首轮会按首轮段发一次并附承接提示。
  - 开场历史中的系统提示会在新会话首步对齐为当时真正渲染的版本。想让新会话首轮即守住中文思考，建议系统提示本身用中文写明思考语言要求（「替换正文·保留工具」）并配合每轮注入。
- **故事记忆摘要**：存在摘要且不晚于截取末轮时可勾选带入（新会话开启故事记忆则设为初始记忆，否则作为前情提要置于开场对话最前）。
- **不带内容**：历史中的每轮注入原文、世界书触发原文、工具调用与工具结果不会带入开场对话（同一轮多步正文合成纯文本）。本会话修改过的世界书会整份随预设保存，不改动原角色卡。
- **与开分支的区别**：开分支是一次性克隆会话；存成预设得到的是可编辑、可反复套用的结构化开局模板。

## 改写注入与会话沙盒

- **会话沙盒**：支持「不设 / 仅观察 / 受控 / 严格」档位，可按官方来源包放行或拦截宿主注入（严格档放行工具包时会自动恢复对应核心消息类型，不半截放行）。
- **改写注入（高级）**：将宿主注入的某段内容替换为自定义正文，仅对本会话生效。
- **疑似未登记注入**：不在已知清单中却进入模型上下文的内容（如第三方插件会话上下文）会被审计记录并默认放行；每条可设为「本会话阻断」（下一轮生效）或「全局记住」（对所有会话提前拦截）。DSH 直接写入会话历史的系统通知仅记录不拦截。

## 全局设置页（左侧栏「预填装」）与顶栏角标

- **全局设置页**：在 DSH 左侧栏点击「预填装」打开。顶部提供 4 张可点击快筛的 KPI 卡（运行中会话 / 已套预设 / 每轮注入开 / 拦截中），下方目录吸顶并随滚动高亮：
  - **总览**：4 组筛选（全部 / 运行中 / 已自定义 / 跟随默认）+ 搜索 + 紧凑双行微卡 + 10 条分页，支持一键跳回会话并弹出卡片。
  - **新会话默认**：统一配置新会话默认的每轮注入（策略与编辑器内容分区 + 未保存暖色底栏）与会话沙盒。
  - **资源库**：按工作区切换并筛选预设、角色卡、积木与塔，双列微卡网格管理导出与两步确认删除。
  - **偏好 / 实验 / 开发者**：设置动效档位（完整 / 简洁 / 关）、实验总开关，开发者选项与危险重置区独立折叠隔离。
- **会话右上角顶栏角标（DSH `0.2.2-rc.5`）**：全默认态自动静默隐藏；存在非默认配置时以 24px 胶囊展示当前模式（纯净 / 接管 / 角色卡 / 预设 / 严格拦截等，变更待生效时尾附「下轮生效」），点击弹出三段式摘要（含当前真实模型名）并支持一键开卡或跳转设置页。

## 文件与数据路径

| 文件 | 职责 |
| :--- | :--- |
| `index.js` | 引导层：按 `impl.js` 修改时间动态加载（改它需要重启） |
| `impl.js` | 宿主壳：HTTP 路由（`state` / `summary` / `draft` / `packs` / `cards` / `memory` / `usage` / `ping`）、状态读写与迁移、轮次闩锁与预填装物化 |
| `gate.js` | 核心引擎：闸门、系统提示接管、注入过滤、每轮注入与合成轮（按 mtime 热替换） |
| `builtin-presets.js` | 内置预设（纯净模式、自定义系统提示、中文官方提示、7 个人格） |
| `blocks.js` | 每轮注入积木与塔的编排及迁移 |
| `session-history.js` | 会话日志转开场对话条目（「从当前会话取」） |
| `constraint-carry.js` | 约束承接：从会话日志识别生效过的每轮约束并编入预设 |
| `turn-lock.js` | 首轮锁定、开跑后套预设与恢复开局快照 |
| `inject-auto.js` | 每轮注入自动收放：规则打分与状态机重放 |
| `enabled.js` | 左栏各功能开关折算视图 |
| `character-cards.js` | SillyTavern V2/V3 角色卡 JSON / PNG 解析、导出与编译 |
| `workspace-instructions.js` | 工作区说明（`AGENTS.md` / `CLAUDE.md`）闸门逻辑 |
| `sandbox*.js` | 会话沙盒：拦截规则表、来源包、视图与追踪审计 |
| `injection-audit.js` | 未登记注入审计与阻断/全局记住判定 |
| `inject-once.js` | 旧版单次注入迁移兼容 |
| `reasoning-prefix.js` | 实验：思考前缀本地代理（默认关，**已冻结**） |
| `client.js` | 浏览器端：输入槽胶囊、顶栏角标、弹出卡片、左侧栏设置页与 `summaryStore` 轻量轮询 |

- **全局状态文件**：`<DSH_HOME>/prefill/state.json`
- **工作区预设**：`<工作区>/.dsh-prefill/packs.json`
- **工作区角色卡**：`<工作区>/.dsh-prefill/cards/`
